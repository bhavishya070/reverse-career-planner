# Reverse Career Planner

## Overview

Reverse Career Planner is an AI-powered web application that helps users achieve their dream careers through personalized learning roadmaps. By analyzing a user's target career, current skills, and timeline, the application generates a structured plan to bridge skill gaps and achieve career goals efficiently.

## Features

* Career roadmap generation
* Skill gap analysis
* Personalized learning paths
* Project recommendations
* Certification suggestions
* Interview preparation strategies
* Career planning based on user goals and timeline

## Technologies Used

* Python
* Streamlit
* Google Gemini AI
* python-dotenv

## How It Works

1. Enter your desired career.
2. Select the timeline to achieve your goal.
3. Provide your current skills.
4. Generate a personalized roadmap.
5. Follow the suggested learning path, projects, certifications, and interview preparation plan.

## Installation

```bash
pip install -r requirements.txt
streamlit run app.py
```
