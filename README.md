# 🚀 Reverse Career Planner

## Overview

Reverse Career Planner is an AI-powered web application that helps users achieve their dream careers through personalized roadmaps. Users can enter their target career, current skills, and timeline, and the application generates a detailed step-by-step plan to reach their goals.

The project supports multiple languages, cloud-based AI models, and local AI inference, making career guidance accessible and flexible for different users.

## Features

* 🎯 Personalized career roadmap generation
* 🌐 Multi-language support (English, Hindi, Telugu)
* 🤖 AI-powered career guidance
* 🔑 BYOK (Bring Your Own Gemini API Key)
* 🖥️ Local AI inference using Ollama
* ☁️ Gemini API integration
* 📈 Skill gap analysis
* 🛠️ Recommended projects and certifications
* 💼 Interview preparation guidance
* 💰 Salary expectation insights

## Technologies Used

* Python
* Streamlit
* Google Gemini API
* Ollama (Local AI)
* Python Dotenv
* Requests

## How It Works

1. Select your preferred language.
2. Choose an AI provider (Gemini API or Ollama).
3. Enter your desired career.
4. Specify your current skills and target timeline.
5. Generate a personalized roadmap.
6. Receive AI-generated guidance, certifications, project ideas, and interview preparation tips.

## AI Features

### Gemini API

Users can generate roadmaps using Google's Gemini AI models.

### BYOK (Bring Your Own Key)

Users can provide their own Gemini API key for personalized access.

### Ollama Local AI

The application supports local AI inference through Ollama, allowing users to generate roadmaps without relying entirely on cloud-based AI services.
